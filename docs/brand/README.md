# phpgraph's logo

The mark is a small graph whose answer stands out, in indigo: the node your question leads to. It is drawn like
[Airlock](https://github.com/alpine-ronin/airlock)'s and [Sherpa](https://github.com/hbenabdallah/sherpa)'s: the
same tile, stroke and round caps, ink and paper, one accent. The nodes are dots wider than the stroke, so they don't
read as the edges' ends.

| File | Use |
|---|---|
| `logo.svg` | The lockup (mark and wordmark) on light backgrounds |
| `logo-dark.svg` | The lockup on dark backgrounds |
| `mark.svg`, `mark-dark.svg` | The mark alone, on light or dark backgrounds |
| `icon.svg` | The app icon: the mark on a dark tile |
| `icon-512.png` | The GitHub avatar (square; GitHub rounds it) |
| `social-preview.png` | The repository's social preview, 1280 × 640 |

The wordmark is drawn as paths, so the SVGs need no font: Space Grotesk SemiBold for `phpgraph`, JetBrains Mono for
the tagline on the social preview (both under the SIL Open Font License).

| Colour | Hex |
|---|---|
| Ink | `#12161C` |
| Paper | `#F6F5F1` |
| Indigo, on light | `#4F57C4` (5.5:1 on paper) |
| Indigo, on dark | `#989DE1` (7.1:1 on ink) |

Both indigos keep the hue of PHP's `#777BB4`.

On GitHub: the avatar is set in the account's or organisation's profile settings, the social preview in the
repository's Settings, General, Social preview.
